# dialog-analyze

## Перед запуском создайте у себя в корне проекта .env файл и положите 2 переменные
1) OPENAI_API_KEY - ваш персональный ключ для работы с ChatGPT API
2) OPENAI_API_URL - URL-адрес ChatGPT API
3) OPENAI_MODEL - модель ChatGPT, по умолчанию gpt-4o-mini
3) выполните команду docker compose up -d
